## 🛠️ Stack Tecnológico Principal

* **Backend:** Python, Django 5.x, Gunicorn, REST APIs.
* **Bases de Datos & ORM:** PostgreSQL (Neon Serverless), SQLite, Django ORM, migraciones avanzadas.
* **DevOps & Despliegue:** Docker, Docker Compose, Render, Ubuntu Server (Linux), Git & GitHub, PowerShell.
* **Frontend & UI:** Tailwind CSS, Alpine.js, Bootstrap, Jazzmin (Admin SaaS), JavaScript, HTML5/CSS3.
* **Automatización & Reportes:** Selenium (Automatización de Redes/ONUs), xhtml2pdf, openpyxl (Excel), pycairo.

## 📂 Proyectos Destacados

### 1. 🍃 AUSEN - Sistema de Gestión de Vacaciones y Licencias
Solución integral desarrollada para optimizar la gestión de recursos humanos en cooperativas y PyMES, digitalizando solicitudes, aprobaciones y control de ausentismo mediante métricas en tiempo real.
* **Características Clave:** Motor inteligente de feriados, cálculo flexible (días corridos/hábiles), algoritmo LCT de antigüedad, notificaciones por correo y reportes PDF.
* **Stack:** Python, Django 5, PostgreSQL (Neon), Tailwind CSS, Alpine.js, Docker, Render.
* 👉 **[Ver documentación completa y capturas de pantalla](./projects/ausen/README.md)**

### 2. 🌳 ArboStock - Sistema de Gestión de Stock
Aplicación web robusta diseñada para el control integral de inventarios, trazabilidad de movimientos, gestión de stock en tránsito (pendientes) y generación automatizada de remitos digitales.
* **Características Clave:** Control de entradas/salidas, roles y permisos granulares de staff, reportes ejecutivos en PDF y Excel, interfaz minimalista adaptada en modo claro/oscuro.
* **Stack:** Django 5, PostgreSQL (Neon), Docker, Tailwind CSS, Jazzmin.
* 👉 **[Ver documentación completa y capturas de pantalla](./projects/arbostock/README.md)**
